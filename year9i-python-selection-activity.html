Mission 3 — Add ELIF

Now we need three possible results.

75 or more → Issue Fine
70–74 → Warning
Below 70 → No Action

speed = int(input("Enter speed: "))

if speed >= 75:
    print("Issue Fine")
elif speed >= 70:
    print("Warning")
else:
    print("No Action")
